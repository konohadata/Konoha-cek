🔍 Keterangan Tiap Fitur
🆔 NIK Dukcapil
Rp2.000
Cek data kependudukan berdasarkan NIK 16 digit dari database Dukcapil.
Output:
  • Nama lengkap
  • Tempat & tanggal lahir
  • Jenis kelamin
  • Agama, gol darah, pendidikan
  • Status pernikahan & keluarga
  • Alamat lengkap
GET /api/cek_nik?nik={NIK}&key={API_KEY}
🏠 KK Dukcapil
Rp4.000
Cek data Kartu Keluarga berdasarkan No. KK 16 digit.
Output:
  • No. KK & jumlah anggota
  • Kepala keluarga (lengkap)
  • Seluruh anggota keluarga
  • Data KK lama & terbaru
GET /api/kk?nokk={NOKK}&key={API_KEY}
👤 Nama Dukcapil
Rp2.000
Cari data kependudukan berdasarkan nama lengkap.
Output:
  • Multiple hasil (kalau ada)
  • NIK, alamat, umur, pekerjaan
  • Data orang tua
GET /api/cek_nama?nama={NAMA}&key={API_KEY}
📱 NIK to HP
Rp2.000
Cari nomor HP & data kebocoran dari NIK/nama/email/HP.
Output:
  • Nomor HP (multiple)
  • Provider (Telkomsel, dll)
  • Tanggal registrasi
  • Sumber kebocoran
GET /api/data-bocor?q={NIK}&key={API_KEY}
📇 GetContact
Rp2.000
Cek nama pemilik nomor HP dari database komunitas GetContact.
Output:
  • Nama pemilik
  • Operator
  • Tags (nama panggilan)
  • Status spam & suspicious
GET /api/getcontact?nomor={HP}&key={API_KEY}
🔗 NIK to KK
Rp2.000
Konversi NIK ke No. KK dari database Dukcapil.
Output:
  • No. KK
  • Nama lengkap
  • Tempat & tanggal lahir
  • Jenis kelamin
GET /api/nik2kk?nik={NIK}&key={API_KEY}
🚗 Cek Data Kendaraan
Rp2.000
Cek data kendaraan berdasarkan plat nomor.
Output:
  • Merk, tipe, tahun, warna
  • CC, BBM, no rangka/mesin
  • Nama pemilik & NIK
  • Status pajak & exp
GET /api/nopol?plat={PLAT}&key={API_KEY}
📸 NIK to Foto
Rp4.000
Cek data kependudukan + foto KTP + family tree.
Output:
  • Data pribadi lengkap
  • Foto KTP (base64)
  • Family tree (keluarga)
GET /api/nikfoto?nik={NIK}&key={API_KEY}
💳 Cek BPJS-Kes
Rp2.000
Cek data BPJS keluarga berdasarkan NIK.
Output:
  • Total anggota keluarga
  • Nama setiap anggota
  • Jenis kepesertaan
  • Status (AKTIF/TIDAK)
GET /api/keluarga_bpjs?nik={NIK}&key={API_KEY}
⚠️ Catatan Penting
  • Harga di atas = biaya per 1x cek
  • Setiap request kepotong dari saldo user
  • Kalau data ga ketemu → saldo REFUND otomatis
  • Token API ada limitnya, cek sisa pake field tokens_remaining
  • Jangan share API key ke siapapun
  • Base URL bisa berubah kalo tunnel restart
  • Owner mode GRATIS (buat owner bot doang)
